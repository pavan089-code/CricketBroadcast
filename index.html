Normally filled automatically. For a restricted league page, enter its league ID or use a match link containing leagueId.

All URL parameters
ParameterRequiredWhat it does
matchIdYesThe CricClubs match to follow.
leagueIdFor live scoresValidated CricClubs league ID. Filled by setup; never guessed.
clubIdNoBackward-compatible alias for leagueId.
viewNoscorebug for the existing live bar or scorecard for the full live scorecard. Omit it to keep the existing scorebug view.
themeNoOne of the themes above. Defaults to modern-light.
logoNoShows a sponsor logo in the top-right corner (1 or 2).
debugNoSample data instead of a live match: 1 first innings, 2 chase, 3 result, 4 toss, 5 no logos. Add card=wicket|milestone|partnership|boundary to hold a sample card on screen.
modeNoreplay cycles through a recorded match to test transitions.
quietNoTurns off the event cards (wicket, fifty, partnership, boundary) and shows only the bar.
refreshNoPoll interval in milliseconds, clamped to 1000–10000 (default 1500).
nostatsNoOpts this browser out of anonymous usage statistics.

Open source on GitHub. Anonymous usage statistics help improve the overlay; add ?nostats=1 to opt out.
